# Chic Clothing eCommerce Platform

This repository contains a full-stack eCommerce application for a premium clothing brand, built with:

- Frontend: Next.js (App Router), React, Tailwind CSS
- Backend: Node.js, Express.js, MongoDB (Mongoose)

## Structure

- `frontend/` – customer-facing storefront and admin dashboard
- `backend/` – REST API, business logic, and database models

## Getting started

1. Backend
   - Copy `backend/.env.example` to `backend/.env` and fill in values.
   - Run:
     - `cd backend`
     - `npm install`
     - `npm run dev`

2. Frontend
   - Run:
     - `cd frontend`
     - `npm install`
     - `npm run dev`

The frontend will communicate with the backend via REST APIs under `/api/v1`. More details will be added as features are implemented.
